# Code of Conduct

We want Sender API to be a respectful, constructive project for everyone.

## Expected behavior

- Be welcoming and considerate.
- Discuss ideas and code, not people.
- Accept constructive feedback and explain disagreements clearly.
- Protect private information and report security issues privately.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, deliberate
disruption, and sharing private or secret information without permission are
not acceptable.

Project maintainers may remove or edit contributions that violate this code
and may restrict participation when necessary to keep the project safe.

To report a conduct concern, contact the repository maintainers privately
through GitHub.
