# Support

Start with the [README](README.md) and the development notes in
[CONTRIBUTING.md](CONTRIBUTING.md).

For a reproducible bug, open a bug report with the smallest safe reproduction
and the output of the relevant checks. Remove credentials, tokens, email
addresses, and production data first.

For feature ideas, explain the user problem and the expected behavior in a
feature request.

Never use a public issue to report a security vulnerability; follow
[SECURITY.md](SECURITY.md) instead.
